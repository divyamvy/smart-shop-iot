# Smart Shop IoT System

An automated IoT-based smart shopping cart and billing system.

## Repository Structure

* **`/arduino/cart_node`** — Microcontroller sketch (`cart_node.ino`) for the shopping cart hardware node.
* **`/arduino/shop_node`** — Microcontroller sketch (`shop_node.ino`) for the central shop/billing node.
* **`/frontend`** — Web-based billing and monitoring dashboard (`index.html`, `style.css`, `script.js`).
* **`Smart_shop_report.pdf`** — Complete project report, system architecture, and documentation.
